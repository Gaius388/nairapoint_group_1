## Dataset Setup

The dataset (`group01_pos.npz`) is not included in this repository, in accordance with the project submission requirements.

To run the project:

1. Obtain the original dataset from the group or the course-provided source.
2. Create a folder named `data` in the project root directory.
3. Place `group01_pos.npz` inside the `data` folder.
4. Run the notebook or execute `run_pipeline("data/group01_pos.npz")`.
